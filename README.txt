GLASSSTOCK — ПЕРВЫЙ ЗАПУСК

Состав:
- index.html — интерфейс
- style.css — оформление
- app.js — логика и подключение к Supabase
- manifest.webmanifest — параметры установки
- service-worker.js — кэш оболочки приложения
- icon.svg — значок

ВАЖНО:
1. Приложение требует публикации на HTTPS. Открытие локально через content:// не подходит для установки PWA.
2. В app.js находится только публичный publishable key Supabase. Никогда не вставляйте сюда service_role/secret key.
3. В Supabase включите подтверждение email либо используйте подтверждённые аккаунты согласно настройкам проекта.
4. Первый зарегистрированный пользователь создаёт склад. Остальные регистрируются отдельно и вводят код приглашения.
5. Движения остатков проводятся через серверную RPC-функцию, чтобы параллельные операции не затирали остатки.
6. Экспорт JSON — резервная копия. Функция импорта пока не включена.
7. Офлайн-кэширует только оболочку интерфейса; для чтения и изменения склада нужен интернет.

Проверить приложение перед рабочим использованием:
- регистрация и вход;
- создание рабочего пространства;
- добавление, изменение и удаление позиции;
- приход, расход и коррекция;
- вход вторым аккаунтом по коду приглашения;
- синхронизация на двух устройствах.
